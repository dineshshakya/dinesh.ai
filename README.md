# dinesh.ai

Personal brand site — **Finance × AI** — built by hand and hosted free on GitHub Pages.

## Live site

- https://dineshshakya.github.io/dinesh.ai/

## Custom domain

The `CNAME` file points this repo at `dinesh.ai`. To use it, buy the domain from a
registrar and point its DNS at GitHub Pages (A records to GitHub's IPs, or a CNAME
to `dineshshakya.github.io`). Note: as of September 2026, `dinesh.ai` is registered
to someone else through November 2027.

## Deploy

Pushing to the `main` branch redeploys the site automatically via GitHub Pages.
