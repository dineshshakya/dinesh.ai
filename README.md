# dinesh.ai

Personal brand site — **Finance × AI** — built by hand and hosted free on GitHub Pages.

## Live site

- https://dineshshakya.github.io/dinesh.ai/

## Custom domain (later)

To serve this from the real `dinesh.ai`, buy the domain from a registrar and add a
`CNAME` file containing `dinesh.ai`, then point DNS at GitHub Pages (A records to
GitHub's IPs, or a CNAME to `dineshshakya.github.io`). Note: as of September 2026,
`dinesh.ai` is registered to someone else through November 2027, so the CNAME file
has been left out for now — the github.io URL above is the working free address.

## Deploy

Pushing to the `main` branch redeploys the site automatically via GitHub Pages.
